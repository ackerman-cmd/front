# Афиша

Адаптивная статическая вёрстка сайта концертно-экскурсионных программ по макетам Figma на HTML и CSS.

## Запуск

Для инструментов разработки нужен Node.js 22.13+ в ветке 22 или Node.js 24+.

```sh
npm ci
npm run dev
```

Страница доступна по адресу http://127.0.0.1:4173. Можно также открыть `index.html` напрямую.

## Команды

| Команда                | Назначение                                   |
| ---------------------- | -------------------------------------------- |
| `npm run format`       | Автоформатирование Prettier                  |
| `npm run format:check` | Проверка форматирования без изменения файлов |
| `npm run lint`         | Проверка HTML, CSS и служебных Node-скриптов |
| `npm run build`        | Создание статической сборки в `dist/`        |
| `npm run check`        | Проверка форматирования, линтеры и сборка    |
| `npm run preview`      | Локальный просмотр готовой сборки            |

## Структура

- `index.html` — разметка страницы и статического календаря.
- `styles.css` — стили и адаптивные состояния.
- `assets/` — изображения, иконки, локальные шрифты и их лицензия.
- `scripts/` — сервер разработки и скрипт сборки; в браузер не загружаются.
