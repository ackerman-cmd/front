# Интерактивный конструктор дашборда

Отдельное клиентское приложение на HTML, CSS и нативных ES-модулях. Для запуска не нужны бэкенд, сборка или npm-зависимости.

Из корня репозитория запустите существующий статический сервер с папкой дашборда:

```powershell
node scripts/serve.mjs dashboard
```

Откройте `http://127.0.0.1:4173/`. Если порт `4173` занят, запустите сервер на другом порту:

```powershell
$env:PORT = '4174'
node scripts/serve.mjs dashboard
```

В этом случае откройте `http://127.0.0.1:4174/`. Для загрузки ES-модулей используйте HTTP, а не `file://`.

- Заголовок каждой карточки можно поменять кнопкой с карандашом. Текст заметки — двойным нажатием на текст или отдельной кнопкой.
- Перетаскивайте карточки за ручку мышью или пальцем. По нажатию на ручку открываются кнопки для перестановки на одну позицию. Они работают и с клавиатуры.
- График имитирует загрузку с задержкой 500–1000 мс и иногда возвращает ошибку. После успешной загрузки значения можно заменить своими.
- Тема, порядок и содержимое хранятся в `localStorage` под ключом `mai.interactive-dashboard` со схемой `version: 1`. Старая или повреждённая запись открывается как пустая доска. Сброс очищает виджеты и сохраняет тему.
